# Password Generator

Create your own secure password with the following options:

### Features:
- [x] Uppercase letters (isUpper)
- [x] Lowercase letters (isLower)
- [x] Numbers (isNum)
- [x] Special characters (isChar)
- [x] Password length (length)

### Clone the Repository
To get started, clone the repository using the following command:

```bash
git clone https://github.com/Ho3einTahan/PasswordGenerator.git
```
